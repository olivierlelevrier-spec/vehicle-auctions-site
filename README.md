# 🚗 VehicleAuctions MVP

Une plateforme d'enchères de véhicules minimaliste et performante.

## Features

✅ **Signup** - Inscription utilisateur  
✅ **Login** - Connexion  
✅ **Browse** - Parcourir les annonces  
✅ **Bidding** - Placer des enchères  

## Deploy sur Vercel (En 1 clic)

1. Allez sur https://vercel.com/new
2. Importez ce repo: `olivierlelevrier-spec/vehicle-auctions-site`
3. Cliquez "Deploy"
4. ✅ C'est en ligne!

## Dev local

```bash
python -m http.server 8000
# Ouvre http://localhost:8000
```

## Architecture

- HTML5 pur (zéro dépendances!)
- CSS Grid responsive
- JavaScript vanilla (localStorage pour l'auth)
- Vercel static hosting
